# قاعدة بيانات القسم المميز للصف التاسع

يطبّق ملف `migrations/001_ninth_featured.sql` بنية البيانات التالية: المواد، الملفات، إعدادات الكود الشامل، أكواد وصول مفردة أو شاملة، سجل استخدام مختصر، وحسابات المشرفين. تُستدعى عمليات القراءة العامة وعمليات المشرف من واجهة Supabase RPC، ولا تتاح الجداول أو روابط Google Drive أو تجزئات الأكواد مباشرةً من الواجهة.

## تفعيل أول مشرف

بعد أن ينشئ صاحب الموقع حسابه من صفحة `/admin`، يضيف مالك مشروع Supabase الحساب كمدير مرة واحدة من محرر SQL في لوحة Supabase. استبدل البريد بقيمة حساب المشرف الفعلية:

```sql
insert into public.ninth_admins (user_id)
select id
from auth.users
where email = 'admin@example.com'
limit 1
on conflict (user_id) do nothing;
```

بعد ذلك لا تستطيع واجهة الويب إضافة مشرفين أو تعديلهم؛ وهذا مقصود حتى لا يتحول رابط لوحة المشرف أو أي مستخدم مسجل إلى صلاحية إدارية. يمكن لمالك المشروع إضافة مدير آخر بالطريقة نفسها من لوحة Supabase.

## ملاحظة حول الحماية

يخفي التطبيق رابط Google Drive إلى أن يُقبل كود صالح. غير أن روابط التنزيل المباشر لـ Google Drive ليست نظام حماية محتوى كاملاً؛ فبعد فتح الرابط يستطيع المستلم نسخه ومشاركته. الأكواد هنا تضبط الاستحقاق والاستخدام، ولا تستبدل منصة ملفات تمنح روابط قصيرة العمر أو نظام DRM.
